# 更新日志

只记录有实际行为变化的版本。2.3.5 及更早的迭代未逐条留档。

## 2.4.1

**云端调用链**

- 服务端返回 400 时，客户端自动去掉请求信封、改用明文重发一次 —— 仍跑 v3 的服务端也能直接用
- 服务端 v4：`/exec` 接受 `cmd` / `command` / `script` / `shell`；`/sys/install` 接受
  `kind` / `manager` / `type`，值认 `pip3`、`python3`、`apt-get`、`node`、`yarn`；
  包列表接受 `packages` / `pkgs` / `names`，也可以是空格分隔的字符串
- 参数确实缺失时，错误信息列出实际收到的字段名，不再只说"必须是非空字符串"

## 2.4.0

**云端**

- 系统提示重写：显式列出可用工具；删掉"一条命令只做一件事""不要串 `&&`"这类过时约束
- `run_shell` 的工具描述同步修改，本地与云端两套提示保持一致

**交付**

- 正文里的 `@路径` 在对话结束后收进末尾的文件卡片，不再重复显示；只剩标点的残行整行丢弃
- 云端会话的产物条修复：以前按"本地文件是否存在"判定，云端永远为空；现在按路径形状识别，
  点开自动下载到缓存再交给系统打开

## 2.3.9

- proot 增加 termux 移植构建作为首选，与原 bionic / static 两套并存，按可靠性依次探测
- 修 `binaryError`：proot `--version` 的输出里没有 "proot" 字样，被误判成损坏
- Python 安装改走 python-build-standalone，解压到 `opt/python` 并建软链，不依赖 apt / dpkg
- `prepareApt` 的 dpkg 状态重建移到宿主侧，不再依赖已经坏掉的 syscall 通道
- 补回 `assets/cloud-workspace.zip`；导出失败给出提示而不是静默返回

## 2.3.8

- 预设改为底部浮层（`PresetSheet`），26dp 顶圆角、计数胶囊、位次角标
- 每条预设带首字徽记与两行摘要；开关为自绘，列表高度随屏幕收敛

## 2.3.7

- 引导页模型名重叠：`Box` 改 `Column`
- apt 读 `/var/lib/dpkg/status` 报 ENOSYS：补 APT sandbox 配置、重建 dpkg 目录与状态文件

## 2.3.6

- 预设改为会话级：设置页只负责管理，对话内右上角「⋯」逐个启用
- 拼接顺序按预设列表顺序，不按勾选先后；人设 → 预设 → 会话补充
- 备份、分支、导入导出全链路携带预设；导入时预设先入库，避免外键回滚
